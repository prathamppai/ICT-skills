THE COMPUTER (Page 69)
------------------------
A computer is an electronic machine that takes input, processes it, and gives meaningful output.

It helps us write, calculate, create, browse, and connect, making it useful in almost every field today.

Hardware and Software:
- Hardware: The physical parts of a computer made of metal, plastic, and wires (e.g. monitor, keyboard, mouse, CPU).
- Software: A set of programs that tells the hardware what to do.

Two main types of software:
1. System Software – Runs the computer and manages its parts. Examples: Windows, Ubuntu, macOS.
   (Info Byte: The most popular system software for smartphones is Android, and for laptops it is Windows.)
2. Application Software – Programs used to do tasks like typing, browsing, or drawing. Examples: MS Paint, Google Chrome, MS Excel.

IPO CYCLE (Page 70)
--------------------
A computer works by following a simple three-step cycle.
It takes input (data), processes it, and gives the final output (information) to the user.

Input --> Process --> Output
           |
        Storage

Input Devices:
Input devices are tools we use to type, click, speak, or scan information into a computer so it can be processed.
- Keyboard: Used to type letters, numbers, and symbols into the computer.
- Mouse: Lets you move the pointer and click on items on the screen.
- Scanner: Copies pictures or documents into the computer as images.
- Stylus: A pen-like tool used to draw or write on touchscreens.

MORE INPUT DEVICES (Page 71)
-----------------------------
- Web Camera: Sends live video to the computer (used in video calls).
- Microphone: Captures your voice or other sounds.
- Barcode Reader: Scans barcodes to quickly enter product details.
- MICR: Reads special characters printed with magnetic ink (used in cheques).

Processor:
The Processor, also called the Central Processing Unit (CPU), is like the brain of the computer.
It carries out instructions, performs calculations, and controls other parts of the system.

The CPU has three main parts:
- Control Unit (CU): Directs how data moves and what each part should do.
- Arithmetic and Logic Unit (ALU): Handles all math and logic operations.
- Memory Unit (MU): Temporarily stores data during processing.

The speed of a CPU is measured in gigahertz (GHz).

Output Devices:
Output devices show us the result after the computer finishes processing.

OUTPUT DEVICES (Page 72)
--------------------------
- Monitor: Shows text, images, and videos on the screen.
- Printer: Prints information from the computer onto paper.
- Speakers: Play sound, music, or voice from the computer.
- Projector: Displays the screen on a large wall or surface for viewing.
- Plotter: Prints large drawings like maps, charts, or engineering designs with high precision.

Computer Memory:
Computer memory is used to store data temporarily or permanently.
It is mainly divided into Primary Memory and Secondary Memory.

Primary Memory:
Primary memory holds data temporarily while the computer is working. Primary memory is fast but has limited storage.
It is of two types:

RAM (Random Access Memory):
- Stores data and programs while the computer is working.
- Data is temporary; it gets erased when the computer is turned off.

MEMORY (Page 73)
-----------------
ROM (Read Only Memory):
- Stores startup instructions needed to turn on the computer.
- Data is permanent; it stays even after shutdown.
- It is a non-volatile memory (keeps data without power).
- Data inside cannot be changed.

Secondary Memory:
Secondary memory stores data permanently, even when the computer is switched off.
It is used to save files, apps, videos, and more for future use.

Examples of Secondary Memory:
- Hard Disk Drive (HDD): Main storage in most computers. Stores files, software, and media for long term. Usually 500 GB to 1 TB or more.
- CD/DVD/Blu-ray Disc: Round discs used for storing music, videos, and files. CD stores ~700 MB, DVD ~4.7 GB, Blu-ray ~25 GB. Inserted into a disc drive.
- Pen Drive (USB Drive): Small, portable storage device. Used to transfer files between computers. Available in 4 GB to 1 TB sizes.
- Memory Card: Tiny card used in phones, cameras, tablets. Stores photos, videos, and files. Comes in sizes like 2 GB, 8 GB, 32 GB, etc.

MOTHERBOARD AND PORTS:
The motherboard, also referred to as a system board, is the main circuit board of the computer.
It connects the CPU, memory, storage, input/output devices, and lets them communicate with each other.

PORTS (Page 74)
----------------
- USB Port: Connects devices like keyboard, mouse, printer, or pen drive using a USB cable. Examples: USB Type-A, USB Type-B.
- Display Port: Connects the monitor or projector to the computer. Examples: VGA (older) and HDMI (for high-quality video and sound).
- Audio Ports: Used to connect speakers, headphones, and microphones. The voice input port is called Microphone Port. The sound output port is often called Line Out.
- Ethernet Port: Used to connect the computer to wired high-speed internet through a LAN cable.
- Power Port: Connects the computer or laptop to a power supply to keep it running. Power ports may be round or rectangular depending on the device model.

Commonly Used Internet Terms:

Bandwidth:
Bandwidth is the amount of data in bits per second (or bytes per second) for digital devices, given time.
It is measured in bits per second or bytes per second.
Here's how internet speed is usually measured:
- Kbps (Kilobits per second) = 1,000 bits per second
- Mbps (Megabits per second) = 1,000 Kbps
- Gbps (Gigabits per second) = 1,000 Mbps
The higher the bandwidth, the faster your internet — like a wider water pipe carrying more water.

Email Address and its parts:
An email address is the digital address you need to understand how an email address is written and what each part means.
An email has two important parts of your email, separated by a dot (.) — no two people can have this same email. It has to own unique identity profile.
For example: abc.abcde@gmail.com
- The part before the @ symbol (here: abc.abcde) is created by the user.
- The part after the @ symbol is the company providing the email service (like gmail.com, yahoo.com, or outlook.com) — no two people can have the same email address, since the entire email must be unique.
